Quick guide

Choose Add Node to place nodes. Choose Add Edge, then click two nodes to connect them.

Select a node or edge to edit its properties. Drag nodes to move them; Alt + drag pans the canvas.

Use Ctrl/Cmd + Z to undo, Shift + Ctrl/Cmd + Z to redo, and Delete to remove a selection.

Load the sample graph to explore an algorithm, then use Run or Step. Save retains one graph in this browser; Export puts JSON in the Import / Export panel.
